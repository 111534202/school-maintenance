# 正式機部署檢查清單

上正式機前、以及每次更新程式之後，在專案資料夾執行：

```bash
php artisan deploy:check
```

它會逐項檢查並標示「通過／警告／錯誤」，旁邊直接寫怎麼改。**有錯誤一定要先處理；警告在正式機也請處理**（開發機可以先不管）。

## 一定要做的設定

| 項目 | 設定（`.env`） | 為什麼 |
|---|---|---|
| 關閉除錯 | `APP_DEBUG=false`、`APP_ENV=production` | 開著的時候，出錯會把程式內部細節、資料庫資訊顯示給使用者 |
| 網站網址 | `APP_URL=https://你的網址` | 網址和密碼才不會明碼傳送；鏡頭掃描 QR／條碼只有 https（或 localhost）能即時使用 |
| 登入 Cookie | `SESSION_SECURE_COOKIE=true`（網站用 https 時） | 登入憑證只走加密連線 |
| 寄信 | `MAIL_MAILER=smtp`，並填好 `MAIL_HOST`、`MAIL_PORT`、`MAIL_USERNAME`、`MAIL_PASSWORD`、`MAIL_FROM_ADDRESS` | 「忘記密碼」的臨時密碼信、派工通知信才會真的寄出（目前 `log` 只寫進 `storage/logs`） |
| 排程 | 伺服器每分鐘執行 `php artisan schedule:run` | 保養工單自動產生、資料備份、AI 預防保養掃描、空間申請清除都靠它；沒設定就都不會跑 |
| 時區 | `APP_TIMEZONE=Asia/Taipei` | 預約時間、保養排定日才不會差 8 小時 |

排程怎麼設：
- Windows：「工作排程器」新增工作，每 1 分鐘執行 `php C:\專案路徑\artisan schedule:run`。
- Linux：`crontab -e` 加一行 `* * * * * php /專案路徑/artisan schedule:run >> /dev/null 2>&1`。

## PHP 設定（`php.ini`）

- `extension=zip`：資料備份（含附件）需要。
- `post_max_size` 至少 8M、`upload_max_filesize` 至少 5M：附件一筆最多 5 個、加起來 5 MB。
- 網站執行的帳號要能寫入 `storage/`、`bootstrap/cache/`。

## 沒有 https 時（例如校內用 `http://192.168.x.x`）

瀏覽器不允許 http 網址即時開鏡頭，所以掃描視窗會自動改成「拍照掃描」：按大按鈕用手機相機拍下條碼或 QR，系統從照片讀取。功能都能用，只是多拍一張照片。要即時掃描請改用 https。

## 每次更新程式之後

```bash
git pull
composer install --no-dev --optimize-autoloader
php artisan migrate --force
php artisan view:clear
php artisan deploy:check
```

更新前先備份資料庫（網站「資料備份」頁的「立即備份」，或 `mysqldump`）。
